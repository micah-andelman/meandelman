H2Woah OTV

When
Fall 2026
Role
Electrical and software lead
Built with
Arduino UNO R4 WiFi, C++, arduino-cli, GitHub Actions

An autonomous vehicle for ENES100's water-sampling mission. It finds itself in the arena from an overhead camera, hugs a wall past the obstacles, threads the limbo gap, then lowers an arm to measure the water's depth, check it for pollution and pump a sample.

I wire the robot and own its code. Teammates write each subsystem as its own Arduino sketch; I port them into one codebase, fix what breaks, and test it in ENES100's browser simulator before it ever touches the hardware. The same source builds for both, behind one flag.

Pluto

When
2026 to now
Role
Solo, successor to Mercury
Built with
Python, Claude Code, Telegram, Google APIs, Fly.io

A personal agent I text on Telegram. Claude Code runs headless on a server with its own tools for my calendar, email, Canvas, grades and the campus buses. It sends a morning brief, an evening check-in and a Sunday review.

Most of the work is in the tools, not the prompt. Each one answers a single question carefully: a guessed exam date never reads like a confirmed one, an unknown room comes back as unknown, and a bus has to beat walking by five minutes before it's suggested.
